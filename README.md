# Lista_compras
Programação mobile
📋 Funcionalidades
Exibir os produtos cadastrados na lista.
Adicionar produtos com nome e quantidade.
Remover produtos da lista.
Exibir a quantidade total de itens cadastrados.
Mostrar uma mensagem quando a lista estiver vazia.
Interface simples e intuitiva.
Observação: algumas funcionalidades ainda estão em desenvolvimento e serão implementadas gradualmente.
🚀 Tecnologias utilizadas
React Native — desenvolvimento da interface mobile.
Expo — ferramentas para desenvolvimento e execução do aplicativo.
React — construção de interfaces.
TypeScript — tipagem estática e maior segurança no código.
Expo Status Bar — controle da barra de status.
